# busly servicecontrol instance delete

Delete a configured ServiceControl instance.

## Usage

```
busly servicecontrol instance delete <name>
```

## Aliases

- `d`

## Arguments

| Argument | Description                                       |
| -------- | ------------------------------------------------- |
| `name`   | The name of the ServiceControl instance to delete.|

## Options

None

## Examples

```
busly servicecontrol instance delete my-servicecontrol
```
