# busly servicecontrol instance set

Set the current ServiceControl instance.

## Usage

```
busly servicecontrol instance set <name>
```

## Aliases

- `s`

## Arguments

| Argument | Description                                     |
| -------- | ----------------------------------------------- |
| `name`   | The name of the ServiceControl instance to use. |

## Options

None

## Examples

```
busly servicecontrol instance set my-servicecontrol
```
