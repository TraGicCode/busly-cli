# busly servicecontrol endpoint delete

Delete (decommission) an endpoint from the current ServiceControl instance.

## Usage

```
busly servicecontrol endpoint delete <id>
```

## Aliases

- `d`

## Arguments

| Argument | Description                              |
| -------- | ---------------------------------------- |
| `id`     | The ID (GUID) of the endpoint to delete. |

## Options

None

## Examples

```
busly servicecontrol endpoint delete 3f2d6c8a-b7a2-4c3f-9c3e-12ab45ef6789
```
